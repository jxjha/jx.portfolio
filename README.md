# Janmesh Jha — Portfolio

Personal portfolio site. Plain HTML, CSS, and vanilla JS — no build step.

## Pages

- `index.html` — showcase (hero, about, been there, projects, gallery portal, music portal, contact)
- `gallery.html` — 3D photo gallery (three.js)
- `music.html` — the record library
- `journey.html`, `revamp.html`, `assortment.html`, `dashboard.html`, `uav.html`, `bias.html`, `agriculture.html` — case studies

## Local preview

Any static server works:

```bash
npx serve .
```

Then open `http://localhost:3000`.

## Deploy

Deployed on Vercel. Every push to `main` publishes.
